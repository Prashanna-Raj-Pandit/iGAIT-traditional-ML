1. class differentiation.R

This R script performs a group comparison analysis between ASD and non-ASD children across ten statistically significant gait features. For each feature, it computes the group means and standard deviations, then selects the appropriate effect size measure based on the distribution of the data — Cohen's d is used for features that pass the Shapiro-Wilk normality test (p > 0.05), while rank-biserial r is used for non-normally distributed features via the Wilcoxon rank-sum test. The second block of the script focuses specifically on the CoM_Y_min feature, computing the observed minimum and maximum values separately for each group to quantify the full spread of the data and support the interpretation that ASD children show greater variability and lower centre-of-mass positions during walking compared to typically developing peers.

2. wilson_and_delonng_imp.R

This R script implements the full traditional machine learning pipeline for ASD classification from gait features. After loading the data, it removes near-zero-variance and highly correlated features to reduce redundancy, then runs Shapiro-Wilk normality tests on each remaining feature to select the appropriate group comparison test — Welch's t-test for normally distributed features and Wilcoxon rank-sum for non-normal ones. Boruta feature selection is then applied using a Random Forest wrapper to identify the eight most informative features, which are carried forward into model training. The data is split 70/30 into training and test sets with stratification to preserve class proportions, SMOTE oversampling is applied exclusively to the training set to address class imbalance, and all features are standardized using statistics from the training set only to prevent data leakage. Three classifiers are trained and evaluated — Logistic Regression with elastic net regularization, Random Forest, and SVM with an RBF kernel — each tuned via five-fold repeated cross-validation scored by ROC-AUC. Final performance is reported on the held-out test set with point estimates and 95% confidence intervals for all metrics.

## What Wilson CI and DeLong CI are doing

**Wilson Confidence Interval** is used for accuracy, sensitivity, and specificity. These three metrics are all proportions — they count how many predictions out of a total were correct. For example, sensitivity = 8 correct ASD out of 9 ASD subjects = 0.889. Because proportions computed from small samples are unreliable, the Wilson interval gives a range of plausible true values. It is preferred over the simpler normal approximation interval (mean ± 1.96 × SE) because the normal approximation breaks down when the proportion is close to 0 or 1, or when the sample is small — both of which are true here with only 21 test subjects. The Wilson interval always stays within [0, 1] and is well-calibrated even with very small n.

**DeLong Confidence Interval** is used specifically for AUC. AUC is not a simple proportion — it is the probability that the model ranks a randomly chosen ASD subject higher than a randomly chosen non-ASD subject, computed from the full ROC curve. The DeLong method treats the AUC as a U-statistic and estimates its variance analytically from the ranks of the predicted probabilities, without requiring any resampling. It is the standard method recommended for AUC confidence intervals in clinical and biomedical machine learning papers and handles correlated ROC curves correctly, which matters here because the same test subjects contribute to all three models.

In short, Wilson answers "what is the true sensitivity likely to be given I observed 8 correct out of 9?" and DeLong answers "what is the true AUC likely to be given the full distribution of predicted probabilities?", and both account for the fact that 21 test subjects is a very small sample.
